Incendium

Incendium is a 2D stealth-action platformer built in the Godot Engine.

    Movement: W, A, S, D (or Arrow Keys)

    Jump: W, Spacebar, or Up Arrow

    Dash: Shift

    Laser Off (Toggle Lever): Q

    Stealth Kill: F

Gameplay Mechanics

    Stealth & Ambush: use the various objects placed as ambush
    Executions: Angels can only be killed by sneaking up on them and performing a stealth execution from behind.
    Environmental Navigation: The celestial ruins feature a mix of vertical platforming and puzzle elements. You will need to utilize operational elevators and correctly toggle sequence levers to bypass hazards.
    Levels: There are 3 stealth levels and 2 platformer levels

Developer Notes & Shortcomings

This project marks our first time doing game development in Godot. Because we were learning the engine, GDScript, and 2D game architecture on the fly, some systems were built iteratively rather than being perfectly optimized from the start. It has been a massive, highly educational experience in managing state machines, node communication, custom UI chatboxes, and dynamic camera mechanics.
